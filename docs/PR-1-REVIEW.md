# PR 1 implementation-plan review

Review date: September 13, 2026.
Baseline: `64303bd32f07449c3f4fae7cc80915cfe8bb29e7` on `migration/tauri-desktop-app`.
The follow-up commit containing this report identifies the reviewed fixes.

## Verdict and scope

This PR is a desktop migration and an initial local editing implementation, not completion of the entire implementation roadmap.
The local-first architecture and reader direction match the product specification.
The roadmap's M0-M8 exit gates are broader than the features implemented here.
Merging this foundation does not establish a completed MVP, full feature parity, or distribution readiness.

| Milestone | Review disposition |
| --- | --- |
| M0 reader reliability | Fixes below address reproduced native failures and session/filesystem regressions; complete fault-injection and recovery acceptance remains open. |
| M1 pages, creation, printing | Local page operations and creation exist; macOS printing uses PDFKit; native page-operation interoperability coverage remains partial. |
| M2 annotations | Highlights, ink, and free text exist; sticky notes, underline, strike-through, shapes, and complete comment workflows remain incomplete. |
| M3 content and decoration | Initial text/image insertion, decoration, attachments, and cover pages exist; complete object manipulation, links, and placement ergonomics remain incomplete. |
| M4 forms and signatures | Basic field authoring and signature appearance placement exist; interactive forms, full field coverage, and protected reusable signature storage remain incomplete. |
| M5 OCR and export | Embedded-text and image export exist; scanned-document OCR, acquisition, language packs, and quality evaluation remain open. |
| M6 editing and protection | Structural compression exists; existing-content editing, encryption, and permanent redaction remain gated by engine decisions. |
| M7 conversion and generation | HTML outlines, CSV, and extractive page indexes are limited outputs; Office formats, translation, and model-backed generation remain open. |
| M8 optional integrations | No collaboration, remote signing, certification, or specialist media integration is delivered. |

The shared mutation contract is still renderer-owned and does not implement the roadmap's full native revision/job architecture or general mutation undo/redo.
The pdf-lib implementation does not replace the requested engine trials.
Signature assets currently use local browser storage; OS-protected encryption is still a required follow-up before claiming the M4 gate.

## Findings corrected in this review

| Finding | Reproduction/evidence | Correction |
| --- | --- | --- |
| CI runtime mismatch | Hosted Test job failed with `Promise.withResolvers is not a function`; PDF.js requires Node 22.13 or newer. | Both workflows use Node 24. |
| Missing coverage interchange output | Sonar configuration expected LCOV while Vitest produced only text and HTML. | Coverage now includes LCOV without relaxing thresholds. |
| Native Create/Combine ignored generated bytes | In the current packaged app, Create PDF opened an existing-file picker and left Home visible. | Added bounded native byte import, private source snapshots, unsaved tracking, and mandatory first Save As. |
| Hidden viewer fit | First native document opened with an empty viewport and negative zoom. | Defer fit until the viewer has dimensions; update rendering after visibility changes. |
| Native tool drawer | The animated drawer was translucent over Home; label and description selectors did not match the markup. | Removed the problematic animation, matched selectors, and bounded the drawer below the toolbar. |
| Annotation toolbar obscured text | Native color controls stacked vertically because their CSS selectors did not match. | Match the controls and position the compact toolbar above the status bar. |
| Bookmarks erased on open | Session reset ran after viewer attachment and cleared its newly loaded outline. | Retain candidate bookmarks across the session commit. |
| Cleanup incorrectly triggered rollback | A release/destroy failure could enter rollback after previous resources were retired. | Commit ownership before cleanup; report cleanup errors without undoing the committed document. |
| Failed mutations leaked or replaced the active proxy | Late outline/attachment failure had no candidate cleanup or previous-revision restoration. | Dispose the failed candidate and restore the previous revision and workspace state. |
| Recovery file removed on open | Recovery-session regression reproduced `discardRecovery` immediately after recovery load. | Keep the recovery file until save or an explicit discard. |
| Destination collision overwrote another writer | Filesystem fault injection created the chosen new destination before persistence; the previous code overwrote it. | New outputs use atomic no-clobber persistence. |
| Existing permissions changed on save | A 0640 file became 0600 after replacement. | Preserve existing destination permissions; new private files retain restrictive defaults. |
| Native printing did not open a dialog | Packaged-app Print created a blank iframe and no system print panel. | macOS uses PDFKit on the main thread with validated edited bytes and the selected range. |
| Test environment errors | Passing tests emitted unsupported blob-navigation and non-constructible URL errors. | Mock only the browser operations absent from the test DOM, without hiding production errors. |

## Evidence boundaries

Native checks use synthetic fixtures and temporary output copies.
The test suite covers parsing, annotation round trips, selected session failures, native IPC contracts, and filesystem behavior; mocked UI tests do not prove native interoperability.
Latest native and packaging results are recorded in [VERIFICATION.md](VERIFICATION.md).

The no-clobber path prevents a new destination from overwriting a concurrent creator.
Existing-file replacement still has a residual concurrent-writer interval between the final fingerprint comparison and rename; it is not a cross-process compare-and-swap.
POSIX permission preservation does not claim preservation of ownership, ACLs, extended attributes, or file flags.
Disk-full injection, a complete native recovery/quit matrix, full tool interoperability, clean-account DMG installation, and signing/notarization remain release acceptance work.

Sonar's workflow can succeed by skipping analysis when its repository token is absent.
A skipped scan is not a successful quality analysis and is separate from the required CI checks.
